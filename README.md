# Enterprise Okta Identity Administration Lab

## Overview

This project demonstrates enterprise Identity and Access Management (IAM) administration using Okta. It simulates common identity administration tasks performed in production environments, including user lifecycle management, group automation, application provisioning, multifactor authentication (MFA), and sign-on policy configuration.

This repository serves as a portfolio project to demonstrate practical Okta administration skills.

---

## Objectives

- Configure users and groups
- Automate group membership using rules
- Assign applications based on department
- Configure MFA policies
- Configure authentication policies
- Demonstrate Joiner-Mover-Leaver (JML) lifecycle management
- Document security best practices

---

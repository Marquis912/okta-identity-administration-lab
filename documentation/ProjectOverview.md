# Project Overview

## Scenario

This project simulates an enterprise Identity and Access Management (IAM) environment using Okta Workforce Identity Cloud.

The environment represents a fictional organization named **Contoso Manufacturing**.

The goal is to demonstrate practical identity administration tasks that are commonly performed by IAM administrators, including:

- User provisioning
- Group management
- Group rules
- Application assignments
- Multi-Factor Authentication (MFA)
- Authentication policies
- Joiner-Mover-Leaver (JML) lifecycle management
- System Log analysis

## Skills Demonstrated

- Okta Administration
- Identity Lifecycle Management
- Access Management
- MFA Configuration
- Security Policy Administration
- Identity Governance Fundamentals
